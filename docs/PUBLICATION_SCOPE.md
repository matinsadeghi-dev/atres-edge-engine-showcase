# Publication and confidentiality scope

This is a portfolio-only repository. Its purpose is to provide a high-level account of project ownership, engineering breadth, interface work, and recognition.

## Intentionally excluded

- Application source code and private implementation details.
- Product hypothesis, detailed use case, strategy, research method, algorithms, scoring, thresholds, or decision logic.
- Database schemas, operational data, wallet/user identifiers, logs, timestamps, metrics, or production examples.
- API keys, tokens, cookies, credentials, private URLs, hostnames, and infrastructure configuration.
- Any claims about profit, accuracy, predictive performance, or real-world effectiveness.

## Visual assets

The PNGs in `assets/` are sanitized illustrative interface previews created for this public showcase. They preserve a dark technical dashboard aesthetic while replacing specific functionality and operational data with generic placeholders. They are not live application captures.

## Before publishing

1. Review the README and screenshots for accidentally specific implementation terminology.
2. Keep the private implementation in its separate repository and do not copy source files here.
3. Never upload `.env` files, credentials, database files, production logs, or exports.
4. Do not describe a distinction beyond its accurate status; Unga Forskare is stated as semifinalist.
